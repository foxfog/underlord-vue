# Система времени и календаря (Time & Calendar System)

В игре реализована комплексная система времени и календаря, поддерживающая два совершенно разных мира:
1. **Земля / Кибергород 2138 года (`calendarType = 'real'`)** — реальный григорианский календарь и точные электронные часы (24-часовой формат).
2. **Новый Мир Overlord (`calendarType = 'new_world'`)** — 360-дневный календарь Нового Мира (12 месяцев по 30 дней) и 4 времени суток.

Вся логика вычислений и форматирования инкапсулирована в `src/renderer/utils/timeCalendar.js` и константах `src/renderer/constants/calendar.js`.

---

## 1. Фазы времени суток (Time of Day)

В игре определены 4 канонических времени суток:

| Идентификатор | Русское название | Иконка | Часы по умолчанию |
| :--- | :--- | :---: | :---: |
| `morning` | Утро | 🌅 | `08:00` |
| `day` | День | ☀️ | `13:00` |
| `evening` | Вечер | 🌇 | `19:00` |
| `night` | Ночь | 🌙 | `23:00` |

### Цикл смены времени суток
При вызове `advanceTime()` (например, по кнопке ⏭ в инвентаре или топбаре):
```
🌅 morning  ──>  ☀️ day  ──>  🌇 evening  ──>  🌙 night  ──>  🌅 morning (day + 1)
```
Переход из `night` в `morning` автоматически увеличивает счетчик дней (`global.day += 1`).

## 2. Календари двух миров

### Земля 2138 (`calendarType = 'real'`)
* **Дата на старте интро**: `18 декабря 2138 года`.
* **Время суток на старте интро**: `evening` (вечер, `20:52`) — окончание рабочей смены на заводе.
* **Отображение времени**: точные цифровые часы `20:52` и фаза `🌇 Вечер`.
* **Формат даты**: `18 дек. 2138`.

### Новый Мир (`calendarType = 'new_world'`)
* **Старт в Новом Мире**: `1-е число 3-го месяца` (Месяц теплого ветра), сезон — `Весна`, время суток — `day` (День).
* **Длительность года**: строго 360 дней.
* **Структура**: 12 месяцев по 30 дней.
* **4 сезона (триады по 3 месяца)**:
  - **Зима** (Месяцы 12, 1, 2):
    - 12: *Месяц льда*
    - 1: *Месяц глубоких снегов*
    - 2: *Месяц уходящих снегов*
  - **Весна** (Месяцы 3, 4, 5):
    - 3: *Месяц теплого ветра* (точка прибытия Момонги в Новый Мир)
    - 4: *Месяц цветущих ветров*
    - 5: *Месяц грозового ветра*
  - **Лето** (Месяцы 6, 7, 8):
    - 6: *Месяц первой искры*
    - 7: *Месяц яростного пламени*
    - 8: *Месяц последнего очага* (лето)
  - **Осень** (Месяцы 9, 10, 11):
    - 9: *Месяц щедрой земли*
    - 10: *Месяц засыпающей земли*
    - 11: *Месяц скованной земли*
* **Дни недели**: 7 дней (День Солнца, День Луны, День Огня, День Воды, День Дерева, День Железа, День Земли).
* **Отображение времени**: только фаза суток (`☀️ День`, `🌙 Ночь` и т.д.), так как в средневековом Новом Мире нет наручных цифровых часов (пока игрок не наденет технологичный шлем или артефакт).

## 3. UI-виджет и модальное окно

* **`TimeCalendarWidget.vue`** (`src/renderer/components/game/ui/TimeCalendarWidget.vue`):
  Компактный виджет в правом углу топбара:
  - Бейдж времени суток и часов (`.time-badge`).
  - Кнопка перемотки времени (`.next-time-btn`), скрываемая при диалогах.
  - Бейдж счетчика игровых дней (`.day-badge`).
  - Бейдж календаря с датой (`.date-badge`).
* **`CalendarModal.vue`** (`src/renderer/components/game/modals/CalendarModal.vue`):
  Полноразмерное модальное окно календаря с интерактивной сеткой месяца, фазами суток, описанием текущего сезона и истории мира.

## 4. Управление из сценариев (JSON истории)

### Инициализация времени Земли 2138 в начале интро:
```json
{ "variable": "global.calendarType = 'real'" },
{ "variable": "global.year = 2138" },
{ "variable": "global.month = 12" },
{ "variable": "global.dayOfMonth = 18" },
{ "variable": "global.day = 0" },
{ "variable": "global.time = '20:52'" },
{ "variable": "global.timeOfDay = 'evening'" }
```

### Переход в Новый Мир (сброс часов и установка дня):
```json
{ "variable": "global.calendarType = 'new_world'" },
{ "variable": "global.year = 0" },
{ "variable": "global.month = 3" },
{ "variable": "global.dayOfMonth = 1" },
{ "variable": "global.day = 0" },
{ "variable": "delete global.time" },
{ "variable": "global.timeOfDay = 'day'" }
```

### Программный API в `useVisualNovel.js`:
```javascript
const { advanceTime } = useVisualNovel()

// Перематывает фазу суток и при необходимости увеличивает день:
const { nextPeriod, dayIncremented, nextFormatted } = advanceTime()
```
