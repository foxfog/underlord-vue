# Интерактивные маркеры сцен и интерьерные переходы (Scene Hotspots System)

Система интерактивных маркеров сцен (**Scene Hotspots**) предназначена для исследования локаций, перемещения по комнатам, зданиям и коридорам без использования карты, а также для взаимодействия с объектами окружения (двери, сундуки, тайники, спуски в подвалы).

Система поддерживает открытие маркеров группами по умолчанию, блокировку/запирание проходов с настраиваемой реакцией (звуки замка, мысли героя, всплывающие предупреждения) и компактное дельта-сохранение в файлах сейвов.

---

## 1. Архитектура и ключевые принципы

1. **Декларативность в `scenes.json`**:
   Любая сцена может содержать массив `hotspots`. Это избавляет от необходимости создавать отдельный `.vue` файл под каждую комнату или коридор — интерьеры можно конфигурировать чисто в JSON.
2. **Нулевой оверхед сейвов (Delta-Save Architecture)**:
   Статические маркеры, определенные в `scenes.json`, **не** записываются в сейвы. В `globalData.sceneHotspots` сохраняются **только те маркеры, статус которых изменился в процессе игры**.
3. **Автоматическое скрытие во время диалогов**:
   Во время активного разговора или показа реплик (`isDialogueActive` / `isInDialogueMode`) все хотспоты автоматически плавно скрываются, чтобы не отвлекать игрока и не перекрывать текст.
4. **Строгий адаптивный дизайн в `em`**:
   В соответствии с `AGENTS.md`, компонент хотспотов использует исключительно единицы `em` (никаких `px` и `rem`), гарантируя идеальное масштабирование на экранах любого разрешения.

---

## 2. Конфигурация хотспотов в `scenes.json`

В описании сцены добавляется поле `hotspots`:

```json
{
  "id": "carne_chief_house",
  "name": "Дом старосты",
  "bg": "images/sprites/backgrounds/grass.webp",
  "worldMap": "newworld",
  "localMap": "carne",
  "locationId": "carne_square",
  "hotspots": [
    {
      "id": "to_square",
      "locationId": "carne_square",
      "label": "Выход на площадь",
      "icon": "exit",
      "target": "carne_village_square",
      "position": { "left": "8em", "bottom": "3em" },
      "status": "active"
    },
    {
      "id": "to_cellar",
      "label": "Люк в подвал",
      "icon": "hatch",
      "target": "inspect_cellar",
      "position": { "right": "8em", "bottom": "3.5em" },
      "status": "locked",
      "lockedAction": {
        "text": "Массивный дубовый люк заперт на навесной замок. Без ключа его не открыть.",
        "sound": "audio/sound/cloth.ogg",
        "notification": "Заперто: нужен ключ от подвала",
        "notificationType": "warning"
      }
    },
    {
      "id": "secret_stash",
      "label": "Потайной тайник",
      "icon": "search",
      "target": "inspect_stash",
      "position": { "left": "50%", "top": "30%", "transform": "translateX(-50%)" },
      "status": "hidden"
    }
  ]
}
```

### Параметры маркера:
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `string` | Уникальный идентификатор маркера в пределах сцены. |
| `label` | `string` | Текстовая подпись под иконкой маркера. |
| `icon` | `string` | Иконка (ключ из словаря или кастомный emoji). См. раздел 3. |
| `target` | `string` | Метка (`label` или `id` шага), куда переходит игра при клике на активный маркер. |
| `position` | `object` | Объект CSS-координат: `{ left, top, right, bottom, transform, zIndex }`. |
| `status` | `string` | Начальный статус: `"active"` (по умолчанию), `"locked"`, `"hidden"`. |
| `condition` | `string` | Выражение условия (например, `"global.has_cellar_key == true"`). Если задано, статус вычисляется динамически. |
| `fallbackStatus` | `string` | Статус при невыполнении `condition` (по умолчанию `"locked"`). |
| `lockedAction` | `object` | Действия, выполняемые при клике на запертый маркер. См. раздел 4. |
| `pulse` | `boolean` | Включать ли анимацию пульсирующего золотого ореола (по умолчанию `true`). |
| `title` | `string` | Кастомный тултип при наведении (если не задан, формируется автоматически). |

## 3. Поддерживаемые иконки (`icon`)

Система поддерживает следующие предустановленные ключи иконок:
* `door` — 🚪 Дверь в помещение / комнату.
* `exit` — 🚪 Выход наружу / на улицу.
* `gate` — ⛩️ Врата, ворота поселения или ограды.
* `hatch` / `cellar` — 🪜 Люк в подвал или погреб.
* `ladder` / `stairs` — 🪜 Лестница наверх или вниз.
* `search` / `inspect` — 🔍 Осмотр объекта или поиск улик.
* `chest` / `box` — 🧰 Сундук или ящик.
* `talk` / `chat` — 💬 Разговор с NPC на сцене.
* `arrow_up` / `arrow_down` / `arrow_left` / `arrow_right` — ⬆️/⬇️/⬅️/➡️ Стрелки навигации.
* *Любой кастомный emoji или символ также поддерживается напрямую.*

## 4. Статусы и реакция на взаимодействие (`lockedAction`)

Каждый маркер может находиться в одном из трех состояний:

### 1. `active` (Активен):
* Отображается с золотой окантовкой и мягким пульсирующим ореолом.
* При клике совершает переход на шаг сюжета `hotspot.target`.

### 2. `locked` (Заперт / Недоступен):
* Отображается с приглушенной бордово-темной стилизацией и миниатюрным бейджем замка 🔒 в верхнем правом углу иконки.
* При клике **не** выполняет переход, а запускает физическую анимацию покачивания (Shake) и выполняет `lockedAction`:
  * `sound` — воспроизводит однократный звуковой эффект (подергивание ручки, щелчок замка).
  * `notification` — показывает всплывающее уведомление игроку (`warning`, `info`, `error`).
  * `text` — выводит мысль героя или реплику в окне новеллы.
  * `goto` — перенаправляет на ветку взлома/диалога (опционально).

Пример `lockedAction`:
```json
"lockedAction": {
  "sound": "audio/sound/cloth.ogg",
  "notification": "Заперто: нужен ключ от подвала",
  "notificationType": "warning",
  "duration": 3000,
  "text": "Массивный дубовый люк заперт на навесной замок. Без ключа его не открыть."
}
```

### 3. `hidden` (Скрыт):
* Маркер полностью исключается из DOM и невидим игроку. Используется для секретов, запертых тайников или путей, которые открываются позже по сюжету.

## 5. Сценарные действия в сюжете (Story Actions)

В файлах сюжета сценарист может изменять статус любых маркеров в реальном времени:

### 1. Универсальный экшен `hotspot`:
```json
{
  "type": "hotspot",
  "scene": "carne_chief_house_hall",
  "id": "to_cellar",
  "status": "active"
}
```

### 2. Удобные алиасы:
* **Открыть / разблокировать**:
  ```json
  { "type": "unlock-hotspot", "scene": "carne_chief_house_hall", "id": "to_cellar" }
  ```
* **Запереть с сообщением**:
  ```json
  {
    "type": "lock-hotspot",
    "scene": "carne_chief_house_hall",
    "id": "to_kitchen",
    "notification": "Кухня закрыта на уборку",
    "text": "Староста попросил не заходить на кухню."
  }
  ```
* **Скрыть маркер**:
  ```json
  { "type": "hide-hotspot", "scene": "carne_chief_house_hall", "id": "secret_stash" }
  ```
* **Показать скрытый маркер**:
  ```json
  { "type": "show-hotspot", "scene": "carne_chief_house_hall", "id": "secret_stash" }
  ```

Если параметр `scene` не указан, действие применяется к текущей активной сцене (`currentScene.id`).

## 6. Дельта-сохранения (Delta-Save Architecture)

Для предотвращения раздувания файлов сохранения:
* Все дефолтные маркеры из `scenes.json` занимают в сейвах **0 байт**.
* В объекте `globalData.sceneHotspots` хранятся исключительно факты модификаций:
  ```json
  {
    "sceneHotspots": {
      "carne_chief_house_hall": {
        "to_cellar": "active"
      }
    }
  }
  ```
* При загрузке итоговый статус вычисляется по цепочке:
  1. `globalData.sceneHotspots[sceneId][hotspotId]` (если перезаписан в игре);
  2. `evaluateCondition(hotspot.condition)` (если задано условие);
  3. `hotspot.status` (статичный статус из `scenes.json`);
  4. `'active'` (дефолт).

## 7. API движка (`useVisualNovel.js`)

Композабл `useVisualNovel` предоставляет методы для программной работы с хотспотами:

* `getHotspotStatus(sceneId, hotspot)` — возвращает итоговый статус (`'active'`, `'locked'`, `'hidden'`).
* `setHotspotStatus(sceneId, hotspotId, status, lockedAction = null)` — изменяет статус и записывает дельту в `globalData`.
* `handleHotspotClick(sceneId, hotspot)` — обрабатывает клик игрока (переход или `lockedAction`).
* `handleHotspotStep(step)` — исполняет сценарный шаг управления хотспотом.

## 8. Архитектура: Свободное перемещение по умолчанию и сюжетные исключения (Map Overrides)

В игре действует правило: **свободное перемещение и отображение сцен — это поведение по умолчанию (дефолт), а воспроизведение сюжетных диалогов и катсцен при входе в локацию — это исключение**.

### 1. Прямой переход на сцену по ID:
Движок `useVisualNovel.js` поддерживает прямой переход на зарегистрированные в `scenes.json` сцены:
`goto('carne_village_entrance')` или `goto('carne_village_square')`.
* Очищаются диалоговые окна и выборы;
* Применяются свойства сцены (`clearCharacters`, переменные сцены);
* Отображаются интерактивные хотспоты сцены;
* **Не требуется создавать искусственные файлы историй или вспомогательные метки с суффиксом `_free` в файлах сюжета**.

### 2. Сюжетные переопределения через `mapOverrides`:
Когда в локации должно произойти сюжетное событие (например, первое прибытие на площадь или диалог со старостой), сюжет устанавливает временное переопределение:
```json
{ "variable": "global.mapOverrides.carne.carne_square = 'carne_square_arrival'" }
```

* **На карте (`carne.vue`)**: точка по умолчанию ведет на саму сцену (`carne_village_square`). Если в `mapOverrides.carne.carne_square` задано событие, карта открывает сюжетную ветку `'carne_square_arrival'`.
* **В хотспотах (`SceneHotspots.vue`)**: маркер перехода проверяет `locationId` или `target` в `mapOverrides`. Если переопределение активно — запускается катсцена; если нет — происходит прямой переход на сцену.

### 3. Автоматическое завершение события:
После завершения катсцены или диалога переопределение просто удаляется:
```json
{ "variable": "delete global.mapOverrides.carne.carne_square" }
```
После этого любые последующие переходы (с карты или через маркеры) ведут напрямую на сцену в режиме свободного исследования без повторения реплик.

### 4. Динамические условия обнаружения (Array Includes):
Для открытия маркеров только после открытия локации на карте используется безопасное выражение:
```json
{
  "id": "to_square",
  "locationId": "carne_square",
  "label": "Центральная площадь",
  "icon": "gate",
  "target": "carne_village_square",
  "position": { "left": "50%", "bottom": "22%", "transform": "translateX(-50%)" },
  "condition": "global.discoveredLocations?.carne?.includes('carne_square')",
  "fallbackStatus": "hidden"
}
```
Движок `expressionEvaluator.js` поддерживает вызовы методов массивов (`.includes(...)`) и опциональную цепочку (`?.`), скрывая маркер (`fallbackStatus: "hidden"`), пока локация не появится в списке открытых мест.
