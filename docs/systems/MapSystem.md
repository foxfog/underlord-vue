# Система карт и открытие локаций (Map & Marker Discovery System)

В игре реализована двухуровневая интерактивная система карт (в стиле Skyrim/RPG) с поддержкой глобального мира, локальных зон, динамического переключения и механизма постепенного открытия точек интереса (Fog-of-War / Marker Discovery).

---

## 1. Архитектура уровней карты

Система разделяет карты на два иерархических уровня:
1. **Глобальная карта мира (World Map)** — отображает масштабные регионы, государства и ключевые пункты (например, Карта Нового Мира `newworld`).
2. **Локальная карта местности (Local Map)** — отображает конкретное поселение, подземелье или окрестности (например, Деревня Карн `carne`).
3. **Городские карты (City Map)** — отдельные карты мегаполисов (например, Кибергород 2138 `cybercity`).

### Доступные компоненты карт (`src/renderer/components/game/maps/`):
* `carne.vue` — локальная карта Деревни Карн (пропорции `2528 / 1686`, спрайт `/images/sprites/maps/carne.jpg`).
* `newworld.vue` — глобальная карта Нового Мира (пропорции `2480 / 1754`, спрайт `/images/sprites/maps/newworld.png`).
* `cybercity.vue` — карта Кибергорода 2138 года (`/images/sprites/maps/city.webp`).

---

## 2. Модальное окно карты (`MapModal.vue`)

Модальное окно карты открывается по клику на кнопку в топбаре (🗺️) или по горячей клавише `M`.

### Возможности:
* **Переключатель уровней (`[ 📍 Локальная ]` / `[ 🌍 Мир ]`)**:
  Автоматически появляется в заголовке, если текущая локация поддерживает оба уровня.
* **Горячая клавиша `L`**: мгновенное переключение между локальной картой и картой мира.
* **Интерактивная навигация**:
  - Масштабирование колесиком мыши или кнопками `+` / `−`.
  - Панорамирование перетаскиванием (drag-and-drop).
  - Клик по маркеру с локальной картой (например, по Деревне Карн на карте мира) плавно переключает отображение на локальную карту деревни.

## 3. Автоматическая привязка сцен к картам (`scenes.json`)

Вместо ручного прописывания смены карты в каждом файле сюжета, сцены декларируют свои карты в `src/renderer/public/data/scenes/scenes.json`:

```json
{
  "id": "carne_village_entrance",
  "name": "Вход в деревню Карн",
  "bg": "/images/backgrounds/carne/entrance.webp",
  "worldMap": "newworld",
  "localMap": "carne",
  "locationId": "carne_village_entrance"
}
```

При переходе на сцену (`type: "scene"`) движок новеллы `useVisualNovel.js`:
1. Автоматически устанавливает `global.worldMap` и `global.localMap`.
2. Обновляет `global.currentLocation` и синхронизирует `settingsStore.currentMap`.
3. Если мир определен как `new_world`, но `worldMap` не указан явно, подставляется `"newworld"`.

## 4. Постепенное открытие маркеров (Fog-of-War / Marker Discovery)

Маркеры на картах не отображаются все сразу: игрок открывает их постепенно по мере исследования мира.

### Хранение состояния
Открытые маркеры сохраняются в реактивном объекте `gameState.global.discoveredLocations`:

```json
{
  "discoveredLocations": {
    "newworld": ["carne_village"],
    "carne": ["carne_village_entrance"],
    "cybercity": ["factory", "home"]
  }
}
```

> [!TIP]
> Поскольку `discoveredLocations` находится в `globalData`, он **автоматически записывается в слоты сохранений** при вызове `saveGame` и восстанавливается при `loadGame`.

### Начальные локации (по умолчанию):
* **Новый Мир**: известна только Деревня Карн (`carne_village`). Точки «Гробница Назарик», «Крепость Э-Рантэл», «Великий Лес Тоб», «Столица Рэ-Эстиз» и «Империя Бахарут» скрыты до их открытия в сюжете.
* **Деревня Карн**: известен только Вход в деревню (`carne_village_entrance`). Площадь, дом старосты, поля и опушка леса открываются по ходу истории.
* **Кибергород**: известны Завод и Дом.

## 5. Сюжетные экшены для открытия маркеров

Для открытия новых локаций в JSON-сценариях используются специальные шаги:

### 1. Одиночная локация
```json
{
  "type": "discover-location",
  "map": "carne",
  "location": "carne_chief_house",
  "title": "Дом старосты"
}
```
* Если передан заголовок `title` или `notification`, игроку показывается уведомление: `«📍 Открыта новая локация: Дом старосты»`.

### 2. Несколько локаций одновременно
```json
{
  "type": "discover-location",
  "map": "newworld",
  "locations": ["great_tomb_nazarick", "e_rantel"]
}
```

### 3. Открытие локации прямо в экшене карты
```json
{
  "type": "map",
  "localMap": "carne",
  "discover": "carne_square",
  "locationId": "carne_square"
}
```

### 4. Альтернативный синтаксис
* `{ "type": "discover-marker", "map": "carne", "location": "carne_fields" }`
* `{ "type": "map-marker", "action": "discover", "map": "carne", "location": "carne_forest_edge" }`

## 6. Как создать новую карту

1. **Создайте Vue-компонент** в `src/renderer/components/game/maps/` (например, `erantel.vue`):
   - Задайте фоновое изображение и CSS-пропорции `--map-aspect-ratio`.
   - Опишите массив точек `locations`.
   - Отфильтруйте массив через `props.globalData?.discoveredLocations?.[mapId]`.
2. **Зарегистрируйте карту** в `src/renderer/components/game/maps/MapModal.vue` в объекте `mapComponents`.
3. **Укажите `localMap` или `worldMap`** в сценах `scenes.json`.
4. **Соблюдайте правило `AGENTS.md`**: все размеры меток, бейджей и шрифтов задавайте исключительно в `em`!
