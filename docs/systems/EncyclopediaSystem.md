# Энциклопедия, Журнал персонажей и Система Симпатии (Encyclopedia & Characters System)

Данный документ описывает систему Энциклопедии, Журнала персонажей и динамических уведомлений об изменении отношений (`symp`) в проекте Underlord-Vue.

---

## 1. Архитектура и композабл `useEncyclopedia.js`

Управление записями персонажей и энциклопедии осуществляется реактивным синглтоном `useEncyclopedia.js`:
- `characters` — реактивный список зарегистрированных персонажей.
- `encyclopediaEntries` — реактивный список открытых статей мира.
- `categories` — иерархическая структура категорий и подкатегорий:
  - `races` («Расы»)
  - `geography` («География») с подкатегориями `settlements` («Населённые пункты»), `regions` («Регионы и земли»), `dungeons` («Подземелья и руины»)
  - `factions` («Фракции и организации»)
  - `lore` («Мир и история»)

### Основные методы:
* `addCharacter(characterData)` — регистрация или обновление карточки персонажа.
* `addEncyclopediaEntry(entryData)` — регистрация или обновление статьи энциклопедии.
* `setBlock({ target, id, blockId, title, text })` — добавление или обновление конкретного информационного блока у персонажа или статьи.
* `removeBlock({ target, id, blockId })` — удаление блока сведений (например, при раскрытии дезинформации).
* `getAttitudeInfo(sympScore)` — расчет статуса отношений (`Преданное`, `Дружелюбное`, `Тёплое`, `Нейтральное`, `Настороженное`, `Неприязненное`, `Враждебное`), иконки и цвета.
* `getState()` / `loadState(state)` / `resetEncyclopedia()` — сохранение и загрузка состояния в `gameState.global.encyclopedia`.

---

## 2. Модульная блочная структура заметок

Все описания персонажей и статей энциклопедии строятся из массива блоков `{ id, title, text }`. Это позволяет сюжетным сценариям:
1. Добавлять факты по мере продвижения по сюжету (например, сначала только встреча у ворот, затем сведения о семье, позже — о деревенских тайнах).
2. Обновлять конкретный блок через `action: "set-block"` без перезаписи всего описания.
3. Удалять неактуальные блоки через `action: "remove-block"`.

## 3. Сценарные действия (`type: "journal"` / `type: "encyclopedia"`)

Сценарные шаги могут вызываться как на верхнем уровне сценария, так и внутри действий выборов (`choice.options[].actions`):

### Регистрация персонажа:
```json
{
  "type": "journal",
  "target": "character",
  "id": "enri",
  "name": "Энри",
  "surname": "Эммот",
  "title": "Энри Эммот",
  "avatar": "images/sprites/characters/enri/default.png",
  "sympVariable": "enri_mc_symp",
  "titleVariable": "enri_mc_title",
  "defaultTitle": "Путник",
  "blocks": [
    {
      "id": "meeting",
      "title": "Знакомство",
      "text": "Сельская девушка, встретившая нас у входа в деревню."
    }
  ]
}
```

### Регистрация статьи энциклопедии:
```json
{
  "type": "journal",
  "target": "encyclopedia",
  "id": "carne_village",
  "category": "geography",
  "subCategory": "settlements",
  "title": "Деревня Карн",
  "icon": "🏡",
  "blocks": [
    {
      "id": "general",
      "title": "Общие сведения",
      "text": "Небольшая отдалённая деревня, огороженная деревянным частоколом."
    }
  ]
}
```

### Добавление или обновление отдельного блока:
```json
{
  "type": "journal",
  "action": "set-block",
  "id": "carne_village",
  "blockId": "kingdom",
  "title": "Государство",
  "text": "Деревня расположена на границе Королевства Ре-Эстиз."
}
```

## 4. Система уведомлений о симпатии (`*_symp`)

Движок визуальной новеллы (`useVisualNovel.js`) в функции `applyVariable(expr)` автоматически отслеживает изменение любых переменных отношений (`*_mc_symp`, `*_symp` или `character.*.symp`):
- При повышении значения: всплывает уведомление `❤️ Отношение улучшилось: {Имя} (+X)`.
- При понижении значения: всплывает уведомление `💔 Отношение ухудшилось: {Имя} (-X)`.
- Во время загрузки сохранений (`isRestoringGameState`) уведомления подавляются.

## 5. Карточки в `JournalModal.vue`

Интерфейс журнала (`JournalModal.vue`) отображает персонажей и энциклопедию в двухколоночном виде:
- **Вкладка «Персонажи»**:
  - Слева: список открытых персонажей с аватарами и бейджами отношения.
  - Справа: портрет, полное имя, текущее отношение (рассчитывается реактивно из переменной симпатии), обращение к главному герою (из `global.*_title`) и список информационных блоков.
- **Вкладка «Энциклопедия»**:
  - Слева: дерево категорий и подкатегорий с открытыми статьями.
  - Справа: карточка статьи с навигационными хлебными крошками и блоками фактов.
- **Адаптивность**: все стили строго используют единицы `em` и `%` в соответствии с главным правилом проекта (`AGENTS.md`).
