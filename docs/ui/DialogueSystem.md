# Система Диалогов

Система диалогов включает в себя две важные особенности: многошаговые диалоги и автоматическое скрытие элементов UI.

## Многошаговые диалоги (Multi-Step Dialogue)

Многошаговые диалоги позволяют разделить текст одного диалогового блока на несколько шагов, которые отображаются по очереди при нажатии кнопки "Продолжить". Текст каждого шага накапливается и отображается вместе с предыдущими шагами.

### Синтаксис

```json
{
  "type": "dialogue",
  "id": "unique_id",
  "steps": [
    { "text": "Первый текст" },
    { "text": "Второй текст" },
    { "text": "Третий текст" }
  ]
}
```

### Примеры

**С персонажами:**
```json
{
  "type": "dialogue",
  "id": "dialogue_sequence",
  "steps": [
    { "character": "mc", "text": "Кто-то...?" },
    { "character": "npc", "text": "Это я! Помните?" },
    { "text": "Их голоса эхом отозвались в пустом здании" }
  ]
}
```

**С действиями между шагами:**
```json
{
  "type": "dialogue",
  "steps": [
    { "text": "Первый текст" },
    { "type": "action", "action": "play_sound_effect" },
    { "text": "Текст после действия" }
  ]
}
```

### Поведение и Typewriter эффект
- **Накопление текста**: Каждый новый шаг добавляется к предыдущим с разделителем `<br>`.
- При включенном медленном выводе текста (Typewriter эффект) печать продолжается только для нового текста, не переписывая уже напечатанное.
- Шаги без явного типа обрабатываются как текстовые (`"type": "text"`).

## Адаптивная высота диалогового окна (Auto-Height & Upward Expansion)

Диалоговое окно привязано к нижней части игрового экрана (`bottom: 0`) и динамически подстраивает свою высоту под объем текста:
* **Минимальная высота**: `min-height: 20%`. При коротких репликах окно сохраняет стандартный аккуратный размер.
* **Расширение вверх**: `height: auto`. Если реплика или нарратив содержат несколько абзацев или большой объем текста, окно не обрезает текст снизу, а увеличивается по высоте и поднимается **вверх**.
* **Предварительный расчет высоты (Ghost-контейнер)**: В компоненте `DialogueBox.vue` используется скрытый контейнер-призрак (`.dialogue-text-ghost`), который сразу резервирует полную высоту текста в потоке документа. Благодаря этому диалоговое окно сразу занимает финальную необходимую высоту, исключая ступенчатые дергания окна вверх во время посимвольного эффекта пишущей машинки (Typewriter).
* **Ограничение максимальной высоты**: `max-height: 85%` с безопасным внутренним скроллом на случай экстремально длинных текстовых блоков.

## Заголовки реплик и имена персонажей (Speaker Title Resolution)

Каждый персонаж в памяти (`characterData`) поддерживает связку трёх полей:
* **`name`** — реальное/базовое имя персонажа (например, `Анон`).
* **`nickname`** — никнейм, зарегистрированный в игре (DMMO-RPG YGGDRASIL). При открытии экрана создания персонажа в поле ввода по умолчанию подставляется текущее `name` для удобства игрока.
* **`title`** — текущее отображаемое обращение / заголовок в шапке окна диалога.

### Приоритет определения заголовка диалога (`resolveSpeakerTitle`):
1. **Явный заголовок шага**: если в шаге диалога указан `title` или `speaker` (например, `"title": "???"` или `"title": "Голос из интеркома"`), отображается именно он.
2. **`character.title`**: если явного заголовка нет, берётся поле `title` персонажа из памяти.
3. **`character.name`**: если `title` пуст или отсутствует, берётся каноническое имя персонажа.
4. **`characterId`**: fallback на идентификатор персонажа, если имя не задано.

### Управление через переменные в сценариях (только в памяти):
> [!IMPORTANT]
> Исходные JSON-файлы в `data/characters/` являются статическими шаблонами по умолчанию и **никогда не перезаписываются во время игры**. Все изменения сохраняются исключительно в оперативной памяти и сериализуются в дельту сейва (`saves/*.json`).

* В начале интро (на Земле):
  ```json
  { "variable": "character.mc.title = character.mc.name" }
  ```
* После создания персонажа в YGGDRASIL и перехода в Новый Мир:
  ```json
  { "variable": "character.mc.title = character.mc.nickname || character.mc.name" }
  ```

## Автоматическое скрытие UI

Система автоматически скрывает определённые UI-элементы (кнопки, панели) при активном диалоге (narration, choices, title, dialogue).

### Конфигурация

Конфигурация устанавливается один раз и действует на все диалоги:
**Файл:** `src/renderer/constants/dialogue.js`

```javascript
export const DIALOGUE_HIDE_UI_CONFIG = [
  'hotbar',
  'map-button'
]
```

При любом диалоге элементы из массива будут автоматически скрыты, а после диалога — показаны.

### Доступные элементы для скрытия
- `hotbar` — нижняя панель инструментов
- `topbar` — верхняя панель (группирует все кнопки)
- `stats-button` — кнопка статистики
- `inventory-button` — кнопка инвентаря  
- `map-button` — кнопка карты
- `dialogue` — диалоговое окно
- `all` — все элементы UI

### Динамическое изменение

Если нужно изменить конфигурацию прямо во время игры из компонента:
```javascript
visualNovel.value.setDialogueHideUI(['hotbar', 'stats-button'])
```
> [!NOTE]
> После перезагрузки истории или сейва конфигурация сбрасывается до дефолтной из `DIALOGUE_HIDE_UI_CONFIG`. Состояние системы не сохраняется в save-файлах.

### Приоритет скрытия
Если элемент явно скрыт через шаг истории:
```json
{ "type": "ui", "action": "hide", "target": ["inventory-button"] }
```
он останется скрытым и после диалога. Система диалогового скрытия не переопределяет явное скрытие.

## Система выборов (Dialogue Choices)

Шаг типа `choice` позволяет предоставить игроку интерактивные варианты ответов или действий.

### Синтаксис

```json
{
  "id": "gate_choice",
  "type": "choice",
  "speaker": "mc",
  "text": "Как ответить собеседнику?",
  "options": [
    {
      "text": "Порассуждать перед ответом",
      "condition": "!global.enri_thought_done",
      "actions": [
        { "variable": "global.enri_thought_done = true" },
        { "type": "dialogue", "character": "mc", "text": "Надо подумать..." },
        { "type": "goto", "target": "gate_choice" }
      ]
    },
    {
      "text": "Любезный ответ",
      "variable": "global.enri_mc_symp += 1",
      "actions": [
        { "type": "dialogue", "character": "mc", "text": "Здравствуйте!" },
        { "type": "goto", "target": "after_choice" }
      ]
    }
  ]
}
```

### Возможности опций выбора:
1. **Условная видимость (`condition` или `if`)**:
   Вариант отображается только если выражение истинно (например, `condition: "!global.enri_thought_done"`). Если условие ложно, кнопка скрывается из интерфейса.
2. **Недоступность (`disabled`)**:
   Отображает кнопку заблокированной (свойство `disabled` с выражением условия).
3. **Модификация переменных (`variable`)**:
   Может быть задана как непосредственно на объекте опции (`"variable": "global.enri_mc_symp += 1"`), так и отдельным шагом в массиве `actions` (`{ "variable": "..." }` или `{ "type": "variable", "variable": "..." }`).
4. **Последовательность действий (`actions`)**:
   Поддерживает реплики (`type: "dialogue"`), нарратив, переходы (`type: "goto"`), показ/скрытие спрайтов персонажей (`type: "show"`, `type: "hide"`) и изменение переменных (`variable`).
   - Если в `actions` указано несколько диалогов подряд, они воспроизводятся последовательно по клику игрока на окно диалога (кнопку продолжения).
   - В конце цепочки действий можно вернуть игрока к выбору или любому другому шагу текущей истории через `{ "type": "goto", "target": "<step_id>" }`. Поиск метки осуществляется среди шагов текущего файла по полям `id`, `label` или `name`. Если метка не найдена в текущем файле, движок расценивает цель как внешнюю историю (`<target>.json`).

### Расположение вариантов на экране (`layout` / `position`):
* **По центру экрана (по умолчанию)**: `layout: "center"` (или если свойство опущено). Варианты отображаются в центрированном оверлее поверх сцены с адаптивными размерами в `em`. Если в шаге задан текст вопроса (`text`) или говорящий (`speaker`), диалоговое окно внизу экрана отображает вопрос, а кнопки выбора располагаются по центру экрана.
* **Внутри/под диалоговым окном (опционально)**: `layout: "dialogue"` (или `layout: "bottom"`, `position: "dialogue"`). Кнопки вариантов выводятся непосредственно внутри нижнего диалогового окна под текстом.
