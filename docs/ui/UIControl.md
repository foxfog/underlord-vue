# Управление интерфейсом и сценарные действия (UI & Scene Control)

Эта система позволяет контролировать видимость элементов интерфейса (кнопок, панелей, топбара), а также управлять кинематографичными эффектами (затемнения, очистка персонажей) напрямую из JSON-файлов истории.

---

## 1. Управление видимостью UI (`type: "ui"`)

### Синтаксис

```json
{
  "type": "ui",
  "action": "show" | "hide",
  "target": ["element-id-1", "element-id-2"]
}
```

### Параметры:
- **`type`**: `"ui"`
- **`action`**: `"show"` или `"hide"`
- **`target`**: массив ID элементов. Если опущен или пуст — применяется ко ВСЕМ элементам (`"all"`).

### Доступные ID элементов:
* `"topbar"` — верхний статус-бар целиком.
* `"hotbar"` — нижняя панель действий.
* `"inventory-button"` — кнопка инвентаря в топбаре (🎒).
* `"journal-button"` — кнопка журнала квестов (📜).
* `"map-button"` — кнопка карты (🗺️).
* `"next-time-button"` — кнопка перемотки времени суток (⏭).
* `"date-badge"` / `"calendar-button"` — плашка даты и кнопка календаря (📅). Видна в реальном мире 2138 года и автоматически скрывается при перемещении в Новый Мир.
* `"stats-button"` — кнопка характеристик (📊).
* `"dialogue"` — окно диалогов и нарратива.
* `"all"` — все элементы интерфейса.

### Примеры:
```json
{
  "type": "ui",
  "target": ["inventory-button", "journal-button", "map-button", "next-time-button"],
  "action": "show"
}
```

### Архитектура модуля:
Логика видимости UI (`baseUiVisibility`, `uiVisibility`, `handleUIStep`, `setDialogueHideUI`, `toggleHideUi`, `hideUi`, `unhideUi`) инкапсулирована в композабле `src/renderer/composables/story/useStoryUI.js` и подключается в `useVisualNovel.js`.

## 2. Кинематографичные переходы (Fade Transitions)

Для плавных переходов между сценами, главами или мирами используется шаг типа `"fade"`:

### Синтаксис:
```json
{
  "type": "fade",
  "action": "out",
  "duration": 2,
  "color": "#000000"
}
```

* **`action: "out"`** (или шаг `"type": "fade-out"`): плавное затемнение/заливка экрана.
* **`action: "in"`** (или шаг `"type": "fade-in"`): плавное появление сцены из цвета заливки.
* **`duration`**: длительность анимации угасания/появления в секундах (число или числовая строка, по умолчанию 1.5).
* **`hold`** (или `delay`): пауза (в секундах), в течение которой экран удерживается полностью залитым цветом:
  - для `action: "in"` — экран сначала держится сплошным цветом указанное время, и только затем начинается плавное проявление сцены (`opacity: 1 -> 0`).
  - для `action: "out"` — экран затемняется, а затем удерживается сплошным цветом указанное время перед переходом к следующему шагу.
* **`color`**: цвет затемнения или вспышки (по умолчанию `#000000`). Поддерживает любые CSS-цвета: `#ffffff`, `white`, `#ff0000` и т.д.
* **`sound`**: опциональный путь к аудиофайлу, запускаемому одновременно со стартом заливки.
* **`wait`**: ожидать ли завершения эффекта (`hold + duration`) перед переходом к следующему сценарному действию (по умолчанию `true`).

### Примеры использования:

* **Классический переход между комнатами через затемнение (0.6 сек):**
```json
{ "type": "fade", "action": "out", "duration": 0.6 },
{ "type": "scene", "scene": "carne_village_square", "clearCharacters": true },
{ "type": "fade", "action": "in", "duration": 0.6 }
```

* **Оглушающее пробуждение / перенос в Новый Мир с шумом в ушах (`tinnitus.mp3`)**:
Экран удерживается сплошным белым цветом 3.589 сек (пока длится звон в ушах), после чего начинает плавно угасать на сцену за 5 сек, одновременно запуская фоновый эмбиент деревни:
```json
{
  "type": "sound",
  "file": "audio/sound/tinnitus.mp3",
  "loop": false,
  "stream": "tinnitus"
},
{
  "type": "sound",
  "file": "audio/background/village-1.m4a",
  "loop": true,
  "stream": "back",
  "delay": 3.589
},
{
  "type": "fade",
  "action": "in",
  "hold": 3.589,
  "duration": 5,
  "color": "#ffffff"
}
```

### Автоматический переход между сценами по умолчанию:
В общих настройках игры (**Настройки -> Общие -> Затемнение между сценами**) доступен переключатель `sceneTransitions` (по умолчанию включен).
* **При переходах по маркерам (hotspots) и карте**: если цель перехода — зарегистрированная сцена (`scenes.json`), движок автоматически выполняет короткое затемнение (0.35 с затемнение → смена сцены → 0.35 с проявление).
* **При сценарных шагах `scene`**: если в истории происходит смена сцены и до/после неё явно не указаны шаги `fade`, автоматически применяется дефолтное быстрое затемнение.
* **Явное отключение в шаге**: если для конкретной сцены автоматическое затемнение не требуется (например, перенос через оверлей шлема или мгновенный кадр), укажите `"fade": false`:
```json
{
  "type": "scene",
  "scene": "carne_village_entrance",
  "fade": false
}
```
* **Кастомная длительность в шаге `scene`**:
```json
{
  "type": "scene",
  "scene": "carne_village_entrance",
  "fade": 0.5
}
```

## 3. Очистка персонажей на сцене (Scene Character Clearing)

Для моментов от первого лица (например, при переходе в новую главу или пробуждении в деревне), когда нужно убрать ранее показанных на экране персонажей:

### Вариант 1: прямо в шаге `"scene"`
```json
{
  "type": "scene",
  "id": "carne_village_entrance",
  "clearCharacters": true
}
```
* `clearCharacters: true` — удаляет всех персонажей со сцены.
* `clearCharacters: ["albedo", "shalltear"]` — удаляет только указанных персонажей.

### Вариант 2: в определении сцены (`scenes.json`)
```json
{
  "id": "carne_village_entrance",
  "bg": "/images/backgrounds/carne/entrance.webp",
  "clearCharacters": true
}
```

### Вариант 3: отдельным шагом
```json
{ "type": "hide-all" }
```
*(или `{ "type": "clear-characters" }`)*

## 4. Синхронизация экипировки персонажа со сценой

В игре реализована двусторонняя реактивная синхронизация экипировки:
* Когда игрок снимает или надевает предмет в модальном окне инвентаря, метод `syncCharacterEquipment(characterId, characterObj)` в `useVisualNovel.js` немедленно обновляет спрайт персонажа на текущей сцене.
* Метод `rebuildEquipmentBySlot(characterId)` пересчитывает видимые слоты и слои спрайтов, гарантируя отсутствие рассинхронизации между инвентарем и отображением героя.

## 5. Экран загрузки игры (`GameLoadingScreen.vue`)

Для предотвращения мерцания интерфейса и подгрузки спрайтов/фонов «на глазах» у игрока при старте Новой Игры или восстановлении сохранений реализован глобальный оверлей загрузки:
* **Полное перекрытие**: сплошной черный фон с `z-index: 99999` перекрывает игровое поле, топбар, боковые панели и сцену новеллы на время асинхронной инициализации (`loadStory()`, декодирование спрайтов, `restoreGameState()`).
* **Рунический индикатор**: в правом нижнем углу экрана (`bottom: 2.5em; right: 3em`) отображается анимированный магический круг Yggdrasil (вращающиеся концентрические кольца с пульсирующим ядром) и статус загрузки («Инициализация мира...», «Загрузка сохранения...»).
* **Плавное исчезновение**: после завершения загрузки экран плавно растворяется (`transition: opacity 0.5s ease-out`), открывая полностью готовую сцену без визуальных скачков.
* **Строгое соблюдение AGENTS.md**: все размеры заданы исключительно в `em` и привязаны к глобальной переменной масштабирования `--size`.

## 6. Быстрое скрытие интерфейса игроком (Ren'Py Style: клавиша H)

Для наслаждения игровым артом, фонами и спрайтами персонажей реализована классическая механика Ren'Py:

* **Клавиша активации**: `H` (поддерживается латинская `H`/`h`, русская раскладка `Р`/`р`, а также физический код клавиши `e.code === 'KeyH'`).
* **Что скрывается**:
  * Окно диалога и нарратива (плавное исчезновение через класс `.invisible` и `opacity: 0`).
  * Варианты выбора (как в окне диалога, так и расположенные по центру экрана).
  * Верхняя панель (Topbar) со всеми кнопками инвентаря, журнала, карты, календаря.
  * Боковые панели (SidebarLeft, SidebarRight).
  * Заголовки глав (`TitleBlock`).
  * Всплывающие toast-уведомления (`Notification`).
  * Интерактивные хотспоты перехода на сцене (`SceneHotspots`).
* **Защита от случайного срабатывания**:
  * Нажатие `H` **полностью игнорируется**, если активно любое поле ввода (`<input>`, `<textarea>`, `<select>`, `isContentEditable`). Это предотвращает случайное скрытие интерфейса при наборе имени, поиске предметов или заполнении форм.
  * Также скрытие заблокировано, если открыто любое модальное окно (`hasModals()` из `useModalStack`), главное меню паузы (Esc-меню), оверлей создания персонажа или видео.
* **Как вернуть интерфейс**:
  * Повторное нажатие `H` (или русской `Р`).
  * Нажатие `Escape`, `Space` (Пробел) или `Enter`.
  * **Клик в любое место экрана** (или тач на сенсорном экране).
* **Безопасность клика**:
  * Во время скрытого интерфейса поверх холста активируется невидимый оверлей `.ui-hidden-overlay` (`position: absolute; inset: 0; z-index: 8000;`).
  * Первый клик по экрану поглощается оверлеем (`stop.prevent`) и только возвращает интерфейс, **не** продвигая диалог и **не** активируя находящиеся под курсором кнопки или маркеры. Следующие клики работают в стандартном режиме.

## 7. Быстрая перемотка текста и диалогов (Ren'Py Style: удержание клавиши Ctrl)

Для быстрого пропуска уже прочитанного текста, тестирования сценариев и комфортной навигации по новелле реализован механизм перемотки при зажатой клавише `Ctrl` аналогично движку Ren'Py:

* **Клавиша активации**: удержание `Ctrl` (поддерживаются как левый `ControlLeft`, так и правый `ControlRight`).
* **Принцип работы**:
  * **Мгновенный сброс пишущей машинки**: если в момент нажатия текст реплики печатается посимвольно (`typewriter`), строка мгновенно дописывается до конца без ожидания анимации.
  * **Высокоскоростное продвижение**: движок циклично продвигает историю каждые 60 мс (`advanceFastForwardStep()`), пока клавиша удерживается. Все последующие реплики выводятся сразу целиком.
  * **Визуальный индикатор**: в верхней центральной части экрана отображается стилизованная плашка `⏩ Перемотка...` с золотым неоновым свечением и анимированными точками (`.vn-skip-indicator`), сверстанная строго в единицах `em` в соответствии с [AGENTS.md](../../AGENTS.md).
* **Гарантированная остановка и безопасность**:
  * **Отпускание клавиши**: при `keyup` события `Control` перемотка немедленно прекращается.
  * **Потеря фокуса**: при переключении окон (`blur`) перемотка безопасно останавливается, предотвращая «залипание» клавиши.
  * **Развилки выбора (`choices`)**: как только сцена доходит до вариантов ответа игрока, перемотка **автоматически останавливается**. Варианты выбора остаются на экране и ждут осознанного решения пользователя.
  * **Окна ввода (`TextInputModal`)**: при появлении запроса на ввод текста (например, выбор имени персонажа) перемотка моментально прерывается.
  * **Модальные окна и меню**: при нажатии `Escape`, открытии инвентаря, журнала, карты или главного меню перемотка сбрасывается.
  * **Окончание сцены**: при достижении последнего шага текущей истории перемотка останавливается и переходит в режим ожидания/свободного исследования.
* **Защита полей ввода**:
  * При фокусе на любом элементе ввода (`<input>`, `<textarea>`, `<select>`, `isContentEditable`) зажатие `Ctrl` полностью игнорируется игровым циклом перемотки. Стандартные системные комбинации клавиш (`Ctrl+C`, `Ctrl+V`, `Ctrl+A`, `Ctrl+Z`, `Ctrl+X`) работают в штатном режиме.
* **Архитектурные сущности**:
  * `src/renderer/composables/useVisualNovel.js`: реактивный флаг `isSkipping`, методы `startFastForward()`, `stopFastForward()`, интервальный цикл `advanceFastForwardStep()`.
  * `src/renderer/components/game/visual-novel/DialogueBox.vue`: реакция на проп `:is-skipping`, мгновенный пропуск `startTypewriter` и сброс `skipTypewriter()`.
  * `src/renderer/components/game/visual-novel/TitleBlock.vue`: пропуск тайпврайтера при `:is-skipping`.
  * `src/renderer/components/game/VisualNovel.vue`: проброс пропов и экспорт методов через `defineExpose`.
  * `src/renderer/views/Game.vue`: глобальная обработка клавиш `keydown`, `keyup`, `blur`, реактивный флаг `isFastForwarding` и индикатор `.vn-skip-indicator`.
  * `src/renderer/public/styles/game/game.css`: стили индикатора, адаптивные через `em` и `--size`.

## 8. Справочник управления в настройках игры (`SettingsControls.vue`)

В меню настроек (`SettingsContent.vue`) добавлена вкладка **«Управление»** (`controls`):
* Содержит подробное наглядное руководство по всем горячим клавишам игры с красивыми бейджами клавиатурных клавиш (`<kbd class="key-badge">`).
* Описывает работу:
  * **Быстрой перемотки** (`Ctrl` — удержание);
  * **Скрытия интерфейса** (`H` / `Р`);
  * **Главного меню / Паузы / Закрытия окон** (`Esc`);
  * **Продвижения текста** (`Пробел`, `Enter`, `ЛКМ`);
  * **Переключения масштаба карты** (`L` / `Д`).
* Все размеры и стили оформлены в строгом соответствии с `AGENTS.md` (исключительно единицы `em`, привязка к переменной масштабирования `--size`).
